# diary/journal/ — 账本 / the journal

`YYYY-MM-DD.md`，一天一个文件。**所有检查读这里**：情绪行、岔路行、`## 今天` 摘要、
节数上限、以及「今天写了没有」。

写什么：事实、时间、谁说了什么、哪一步出错、岔路是哪一条。
判据是「三个月后我还能靠它定位」。

不写什么：写给某个人看的信——那在 `diary/letter/`。

## 一天的样子

```markdown
# 2026-11-22

## 10:48 一句话说清这节是什么

情绪：定

正文。一段到三段。

岔路：我当时以为……，其实……
```

## 两条硬规矩

- **每个 `##` 节带一行 `情绪：词`**，词必须在 `relationship.md` 的情绪词表里。
- **`## 今天` 放在最上面**，随写随改；`（HH:mm 更新）` 那个时刻是插件拿去和正文对照的。

旧的账本可能还躺在 `diary/` 根上——插件两处都读，不用搬。
